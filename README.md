# Neon Rift: Survivor

A polished, offline browser survival game designed for GitHub Pages.

## v2 features
- Endless survival waves with escalating difficulty
- Five boss variants with different attack patterns
- 18 in-run upgrades with build combinations
- Permanent workshop upgrades bought with Rift Credits
- 8 local achievements
- Best score, run count and highest wave saved in `localStorage`
- Random run mutator for extra variety
- Dash, shields, orbiting guardian drones, critical hits, piercing shots, explosions and regeneration
- Procedural particles, glow effects, screen shake and browser-generated audio cues
- Pause with `ESC`
- No backend, paid assets, external libraries or build step

## GitHub Pages
1. Create a public repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and open the Pages URL GitHub gives you.

## Controls
- **WASD / Arrow Keys** — move
- **Mouse** — aim
- **Hold left click** — fire
- **Space** — dash
- **Esc** — pause

Everything is client-side, so the game can also be opened directly from `index.html`.
