# Neon Rift: Survivor v3

A polished, free, offline browser survival game designed for GitHub Pages.

## Features
- Endless survival waves
- 5 boss variants with unique attack patterns
- 18 in-run upgrades
- 4 permanent Workshop upgrades
- 8 achievements
- Rift Credits and persistent progression
- 4 active Rift Mutators
- Combo multiplier for aggressive play
- Elite drones and timed Rift Surge events
- Browser-generated audio effects
- Local save system with localStorage
- No external assets, libraries, API keys or server required

## Controls
- WASD / Arrow Keys: move
- Mouse: aim
- Hold Left Click: fire
- Space: dash
- Esc: pause

## GitHub Pages
Upload `index.html` to a repository and enable **Settings → Pages → Deploy from a branch**.
