# Neon Rift v7

Browser roguelite shooter. This patch fixes the ship ability system so ability names and ability functions are separate. Ship cards show the correct ability name and pressing Q no longer throws an error after activation.

## Controls
- WASD / Arrow Keys: move
- Mouse: aim
- Left mouse: fire
- Space: dash
- Q: ship ability
- ESC: pause

Runs fully in the browser with no server or paid assets.
