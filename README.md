# Neon Rift: Survivor v6

A polished offline browser roguelite made as a single HTML file. No backend, paid assets, frameworks, or external libraries are required.

## v6 highlights

- 5 playable ships with different stats and Q abilities
- 24 run upgrades for deeper builds: crit, homing, chain lightning, explosive shots, orbital damage, adrenaline and more
- 10+ enemy behaviors including assassins, splitters, healers, summoners and mines
- 5 boss variants with 3-phase fights
- combo multiplier, Rift Surges and 4 Rift mutators
- persistent Rift Workshop, credits and achievements
- local save via browser `localStorage`
- keyboard + mouse controls

## Controls

- WASD / Arrow keys — move
- Mouse — aim
- Hold Left Click — fire
- Space — dash
- Q — ship ability
- Esc — pause

## GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch** and select the `main` branch and `/root` folder.
5. Save and open the generated Pages URL.
